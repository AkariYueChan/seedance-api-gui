    快速开始
    
  
      
    
    1. 在项目文件夹里双击 一键启动.command。第一次会自动创建 .venv 并安装依赖，然后打开 http://127.0.0.1:6547。终端窗口不要关，关掉服务就停了。
      2. 
    
    2. 到「🔑 API Key」页添加并保存 Key（在火山方舟控制台「API Key 管理」获取），或者点右上角的「API Key」按钮 →「＋ 添加 API Key…」。
      3. 
    
    3. 在「🎬 视频生成」底部先选任务类型，再输入提示词。需要素材的任务会自动列出素材行，每行用按钮选类型、角色、来源，再填 URL 或选文件；全模态参考可以「＋ 添加一行」直到上限。右侧顶部的检查栏会列出还缺什么，有问题的地方用红框标出。点发送按钮下面的「🧾 请求预览」可以打开一个小窗口查看请求代码。
      4. 
    
    4. 点右边的「发送」（或按 ⌘/Ctrl + Enter）。左侧历史栏会新增一条，右上方显示进度；生成完成后可以直接播放和下载。
      5. 
    
    5. 点左侧任意一条历史，可以查看结果，「↩ 重新填写」把当时的提示词、素材和参数填回输入区，「⟳ 再来一次」用相同请求再生成。
      6.

    视频生成
    
  
    接口：POST /contents/generations/tasks 创建异步任务，返回 id；用 GET /contents/generations/tasks/{id} 查询，成功后从 content.video_url 取视频（24 小时内有效）。
    
  
    
    
    任务类型需要的素材支持的模型
    
    
    文生视频只需提示词全部
    
    
    图生视频-首帧1 张图，role = first_frame全部
    
    
    图生视频-首尾帧2 张图，role 分别为 first_frame、last_frame2.5、2.0 系列、1.0 pro
    
    
    全模态参考参考图 / 视频 / 音频（role = reference_*）2.5（图 ≤30、视频 ≤10、音频 ≤10，可只传音频）；2.0 系列（图 ≤9、视频 ≤3、音频 ≤3，音频不能单独传）
    
    
    基于样片生成正式视频1 个 draft_task（样片任务 ID）2.5
    
  
    
  
    首帧、首尾帧、全模态参考三种场景互斥，不能混用。全模态参考可以在提示词里用 @图像1、@视频1、@音频1 指代素材。
    
  
    
    
    模型分辨率时长特有参数
    
    
    doubao-seedance-2-5-260628480p / 720p / 1080p[4,30] 或 -1generate_audio、output_format、draft、omni_reference_task_type、priority、web_search
    
    
    doubao-seedance-2-0-260128480p / 720p / 1080p / 4k[4,15] 或 -1generate_audio、priority、web_search
    
    
    2.0 fast / mini480p / 720p[4,15] 或 -1同 2.0
    
    
    doubao-seedance-1-0-pro-250528480p / 720p / 1080p[2,12]frames、seed、camera_fixed、service_tier=flex
    
  
    

  
    查询历史视频 / 终止任务
    
  
      
    
    • ☁️ 云端视频（左上角按钮或输出区标签）：调用 GET /contents/generations/tasks，可按状态（filter.status）、任务 ID（filter.task_ids，可多个）、推理接入点（filter.model，只支持 ep- 开头的 ID）、服务等级（filter.service_tier，不传时只返回在线 default 任务）筛选，分页 page_num / page_size 取值 [1, 500]。任务在方舟上只保留 7 天，视频地址 24 小时内有效。
      • 
    
    • ⏹ 终止（对话里的「终止生成」、左侧历史悬停的 ⏹、云端卡片）：先查询任务的真实状态，再调用 DELETE /contents/generations/tasks/{id}。只有 queued（排队中） 的任务可以取消，取消后状态变为 cancelled，24 小时后自动删除；running（生成中） 的任务接口不支持取消，只能等完成或超时（可用 execution_expires_after 设置超时，最短 3600 秒）。
      • 
    
    • 🗑 删除云端记录：对 succeeded / failed / cancelled / expired 的任务调用同一个 DELETE 接口，删除后无法再查询；本地历史记录保留。
      • 
  
    

  
    素材要求
    
  
      
    
    • 图片：jpeg / png / webp / bmp / tiff / gif（2.x 另支持 heic / heif）；宽高比 [0.4, 2.5]；边长 [300, 6000] px；单张 < 30 MB。
      • 
    
    • 视频：mp4 / mov（H.264 / H.265）；FPS [24, 60]；单个 ≤ 200 MB；总像素 [407696, 8295044]；2.5 单个 [2,30] 秒（编辑任务 [4,30] 秒），总时长 ≤ 30 秒；2.0 单个 [2,15] 秒，总时长 ≤ 15 秒。只能用 URL 或 asset://。
      • 
    
    • 音频：wav / mp3；单个 ≤ 15 MB；2.5 单个 [2,30] 秒，总时长 ≤ 30 秒；2.0 单个 [2,15] 秒，总时长 ≤ 15 秒。
      • 
    
    • 素材 ID：asset://<ASSET_ID>，来自控制台「素材 & 虚拟人像库」。
      • 
    
    • 整个请求体不超过 64 MB，大文件请用 URL，不要用 Base64。2.x 系列不支持直接上传含真人人脸的参考图或视频。
      • 
  
    

  
    参数要点
    
  
      
    
    • 2.5 的首帧 / 首尾帧、视频编辑、视频延长任务，ratio 只能是 adaptive；视频编辑的 duration 只能是 -1。
      • 
    
    • 1.0 系列的文生视频不支持 ratio=adaptive。frames 须满足 25+4n，并且优先于 duration。
      • 
    
    • 样片模式（draft=true）只支持 480p；样片任务 ID 的有效期为 7 天（2026-10-28 之后创建的为 14 天）。
      • 
    
    • duration 和费用相关。查询结果里的 duration 是总帧数除以 24 后向下取整。
      • 
  
    

  
    技能管理
    
  
    页面分三栏：左是技能列表（顶部「⬆️ 上传技能 / 🐙 GitHub 导入」，下面可以搜索、按来源筛选）；中是选中技能的详情，分「📄 预览（读取 SKILL.md、文件列表、下载 ZIP）/ 🗂 版本（上传新版本、预览或删除某个版本、绑定某个版本）/ ⚙ 配置（内容保护、被哪些智能体引用、删除）」；右是智能体管理：列表、新建、编辑配置（名称、模型、推理参数、系统提示词、上下文压缩、标签、元数据）、技能绑定、工具集与 MCP、版本历史（可以把某个历史版本的配置恢复到表单）、归档和删除。
    
  
      
    
    • 技能来源：ark（方舟预置，只能查看和绑定）、custom（自定义，可以发新版本、开内容保护、删除）、skill_hub（只能绑定）。
      • 
    
    • 上传要求：单个 ZIP、单个 SKILL.md，或保留相对路径的多个文件；每次最多 500 个文件，原始大小合计 ≤ 30 MiB；ZIP 解压后单个文件 ≤ 30 MiB，合计 ≤ 120 MiB；只能有一个顶层目录，目录下直接包含唯一的 SKILL.md；frontmatter 必须有 name（1–64 位，小写字母、数字和 -）和 description。
      • 
    
    • 删除版本：要先删掉所有非最新版本，才能删除最后剩下的最新版本。删除技能前，先在引用它的智能体里移除。
      • 
    
    • 绑定到智能体：POST /agents/{id} 时必须带上当前 version；skills 会整体替换，传 [] 就是清空；最多 50 个；不填版本就用最新版本。已有会话仍然使用旧的智能体版本。
      • 
  
    

  
    历史调用
    
  
      
    
    • 连接本地后端后，每个请求在发出之前都会先完整存入数据库，同时记下当时整个页面的配置（两个工作区的表单、素材、技能绑定和所用的 Key）。
      • 
    
    • ↩ 重新填写：把页面恢复成那次调用时的配置，并跳转到对应的工作区，可以改一改再提交。
      • 
    
    • ⟳ 重发：用原来的报文、原来的 Key 再发一次。重发「创建任务」会再生成一个新任务，同样会产生费用。
      • 
    
    • 默认只显示提交类操作（创建、上传、绑定、删除等），取消勾选可以看到所有查询请求。
      • 
  
    

  
    API Key
    
  
      
    
    • 连接后端时，Key 保存在当前数据库的 api_keys 表里（明文）。页面只拿到 Key 的编号，真正的 Key 由后端在转发时填进去，浏览器里看不到。
      • 
    
    • 没有连接后端（直接双击打开 index.html）时，保存的 Key 存在浏览器的 localStorage 里（明文），公用电脑上不要保存。
      • 
    
    • 右上角的「API Key」按钮显示当前使用的 Key：绿点表示已就绪，红点表示还没有可用的 Key。点它打开菜单，可以切换、测试当前 Key、添加新 Key 或打开管理页；还没有任何 Key 时，点它直接进入添加页面。
      • 
    
    • 每个视频任务会记住用的是哪个 Key，后台查询进度时也用同一个 Key。
      • 
  
    

  
    网络代理
    
  
      
    
    • 只影响后端（server.py）发出的请求，不影响浏览器本身。
      • 
    
    • 「跟随系统代理」会读取 macOS 网络设置，以及环境变量 http_proxy / https_proxy。
      • 
    
    • 测试时会用当前填写的配置去访问 Base URL；只要收到响应（包括 401），就说明网络是通的。
      • 
    
    • HTTP 代理访问 https 地址时会通过 CONNECT 建立隧道，代理账号密码会一起发送。SOCKS5 需要 PySocks，一键启动脚本会自动安装。
      • 
    
    • 代理密码以明文保存在 data/settings.json（权限 600），页面不会把已保存的密码显示出来。
      • 
  
    

  
    数据库
    
  
      
    
    • 默认使用 SQLite（data/seedance.db），不需要账号密码。也可以改用 MySQL 5.7+ 或 PostgreSQL 12+。
      • 
    
    • 切换时会自动建表；勾选后，如果新库是空的，会把当前数据复制过去。原数据库里的数据不会删除。
      • 
    
    • 自动建库需要账号有建库权限（PostgreSQL 需要 CREATEDB）。MySQL 保存大请求体时，可能需要调大 max_allowed_packet。
      • 
    
    • 如果启动时连不上配置的数据库，后端会临时改用本地 SQLite，并在「🛢 数据库」页显示原因。
      • 
    
    • 数据库账号密码以明文保存在 data/settings.json（权限 600）。
      • 
  
    

  
    接口一览
    
  
    Base URL：https://ark.cn-beijing.volces.com/api/v3，鉴权：Authorization: Bearer $ARK_API_KEY
    
  
    
    
    功能方法与路径
    
    
    创建视频任务POST /contents/generations/tasks
    
    
    查询视频任务GET /contents/generations/tasks/{id}
    
    
    视频任务列表GET /contents/generations/tasks?page_num=&page_size=&filter.status=&filter.task_ids=
    
    
    取消 / 删除视频任务DELETE /contents/generations/tasks/{id}（queued → 取消；已结束 → 删除记录；running 不支持）
    
    
    创建技能 / 技能列表POST /skills（multipart）/ GET /skills?source=&name=&limit=&page=
    
    
    技能详情 / 内容保护 / 删除GET / POST / DELETE /skills/{skill_id}
    
    
    版本：创建 / 列表POST / GET /skills/{skill_id}/versions
    
    
    版本：详情 / 删除GET / DELETE /skills/{skill_id}/versions/{version}
    
    
    版本：下载GET /skills/{skill_id}/versions/{version}/content（302，下载地址 1 小时内有效）
    
    
    GitHub 扫描 / 导入POST /skills/github/scan / POST /skills/github/import
    
    
    智能体：列表 / 详情 / 创建 / 更新GET /agents / GET /agents/{id} / POST /agents / POST /agents/{id}
    
  
    

  
    效果问题上报（Seedance 2.x）
    
  
    任务完成后 7 天内可以上报。截图链接要求公网 HTTPS 直链，提交后至少保持 24 小时可以访问。
    

    curl "https://prompt-pilot.cn-beijing.volces.com/case-platform?Action=CasePlatformV1BadcaseReport&Version=2024-01-01" \
  -H "Authorization: Bearer $ARK_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "Id": "cgt-xxxx",
    "Feedback": "问题描述（1-2000 字符）",
    "BadcaseType": "other",
    "ContactInfo": "user@example.com",

    文件夹与项目整理
    
  
      
    
    • 📁＋（左侧栏顶部）新建文件夹，建好后直接输入名称。每次发送生成一个项目，默认名称取提示词第一句的前面部分（最多 24 个字）。
      • 
    
    • 重命名：鼠标移到项目或文件夹上点 ✎，或双击名称；回车保存，Esc 取消。项目名称清空后保存，会恢复为默认名称。对话区顶部的标题也可以双击重命名。
      • 
    
    • 拖动：把项目拖到文件夹上放进去；拖到另一个项目的上半部 / 下半部，放到它前面 / 后面；拖回「未归类」移出文件夹。文件夹之间也可以拖动调整顺序。
      • 
    
    • 点文件夹名称折叠 / 展开。删除文件夹时，里面的项目会移回「未归类」，不会被删除。在文件夹里的项目上继续发送，新项目也会放进同一个文件夹。
      • 
    
    • 连接后端时，文件夹和排序保存在数据库（folders、conv_meta 表）；没连后端时保存在浏览器里。
      • 
  
    

  
    日志
    
  
      
    
    • 顶部「📋 日志」页集中记录重要事件，保存在数据库的 events 表（不连后端时保存在浏览器里）。
      • 
    
    • 类别：提交（发出的创建 / 修改 / 删除请求）、返回（成功响应）、查询（GET 请求）、超时（网络超时，或任务因 execution_expires_after 超时）、错误（HTTP 4xx/5xx、网络错误、生成失败）、任务（任务状态变化、生成完成）、重发、配置（Key、代理、数据库变更）、系统（后端启动、轮询出错）、前端（页面里发生的提示，如无法终止生成中的任务）。
      • 
    
    • 可以按级别、类别筛选和搜索；点任务 ID 可以在「云端视频」里查询，点 #编号可以查看那次调用的完整报文。导航上的红色数字是上次查看之后新增的错误数。

    常见问题
    
  
    
    
    页面提示「网络 / 跨域错误」
    说明是直接双击打开的 index.html，浏览器被跨域拦截了。请用「一键启动.command」启动，再访问 http://127.0.0.1:6547。
    
    
    返回 401 / 403
    API Key 无效、填错，或者没有开通对应的模型。Seedance 2.x 系列需要账户余额大于 200 元或已购买资源包。
    
    
    连不上方舟
    到「🌐 网络代理」点「测试」。如果系统代理不能访问方舟，改成「不使用代理」或填写可用的代理。
    
    
    视频链接打不开
    视频和尾帧地址只有 24 小时有效期，Seedance 2.5 生成的视频最多只能下载 100 次，请及时下载。
    
    
    换了电脑或数据库，Key 没了
    Key 存在当前数据库里。切换数据库时勾选「复制当前数据」，或者在新环境重新添加。
